버전을 베끼지 않고 실측한다
스킬은 먼저 stable 채널과 BOM 을 확인하고, 의존성이 요구하는 compileSdk 가 더 높으면 의존성을 내립니다.
① stable 채널 확인
❯ sdkmanager --list | sed -n '/Available/,$p' \ | grep "platforms;android-3" platforms;android-34 | 3 | Android SDK Platform 34 platforms;android-35 | 2 | Android SDK Platform 35 platforms;android-36 | 2 | Android SDK Platform 36 # android-37 은 목록 위쪽 preview 섹션에만 있다 ❯ sdkmanager "platforms;android-37" Warning: Failed to find package 'platforms;android-37' → compileSdk = 36
② BOM 이 끌어오는 Compose
❯ for b in 2026.06.01 2026.08.00; do curl -s ".../compose-bom-$b.pom" \ | grep -A2 "<artifactId>ui<"; done 2026.06.01 ui 1.11.4 compileSdk 36 2026.08.00 ui 1.12.0 compileSdk 37 요구 # 규칙: 의존성이 요구하는 compileSdk > stable 최신 # → 프리뷰 SDK 를 받지 말고 의존성을 내린다 → compose-bom:2026.06.01 → activity-compose:1.12.4
함정 1 · JDK
brew install --cask temurin@21 (출력 없이 멈춤)
cask 는 보이지 않는 sudo 창을 기다린다. formula 로 설치한다.
함정 2 · AGP 9
'org.jetbrains.kotlin.android' plugin is no longer required
Kotlin 이 AGP 에 내장됐다. 그 플러그인만 지우고 Compose 플러그인은 둔다.
함정 3 · compileSdk
requires … version 37 or later of the Android APIs
android-37 은 preview 다. BOM 을 내린다.
함정 4 · gradlew
Unable to locate a Java Runtime.
gradlew 는 org.gradle.java.home 보다 먼저 java 를 찾는다. dev.sh 가 JAVA_HOME 을 잡는다.
